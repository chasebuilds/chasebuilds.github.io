## What's here

- `index.html` and `styles.css`: one static page with no framework and no build step.
- `img/`: project thumbnails in WebP, made from each repo's own screenshot.
- `notebook-shelf-*.js`: the 3D notebook shelf component from [notebook-shelf](https://github.com/chasebuilds/notebook-shelf).

Each project's live demo is served from its own repo at `chasebuilds.github.io/<repo>/`.
